PHAN CONG CHI TIET CHO NHOM 4 NGUOI
Day04 - Prompt Engineering & Tool Calling

1. MUC TIEU CHUNG

Nhom giu de tai IT Helpdesk de tan dung starter, 30 case co ban va 12 case an toan.
San pham cuoi phai co:
- Prompt va tools declaration ban cuoi.
- Run that cua v0, v1, v2, v3 tren cung bo case.
- 10 case moi cua nhom: 5 single-turn va 5 multi-turn.
- Run 12 case adversarial va phan tich it nhat 3 case.
- UI chat hien tool name, input, result/error va artifact version.
- Transcript, REPORT.md, TEAM.md va muc INDIVIDUAL cua tung nguoi.

Quy tac phoi hop:
- Khong sua eval_base.json va eval_adversarial.json.
- v0 phai chay truoc khi sua system_prompt.md hoac tools.yaml.
- Moi version v1-v3 chi kiem tra mot gia thuyet chinh.
- Chi dung run lam evidence khi provider_error_cases = 0 va measured_cases = total_cases.
- Moi nguoi lam tren branch rieng, co commit ky thuat va tu viet INDIVIDUAL.

======================================================================
2. NGUOI 1 - NHOM TRUONG + PROMPT ENGINEER
======================================================================

Muc tieu:
Lam cho agent hieu dung yeu cau, chon dung tool, biet hoi lai va phan hoi dung format.

File chinh phu trach:
- starter_v0/artifacts/system_prompt.md
- starter_v0/artifacts/version_log.csv
- starter_v0/runs/ (run base v0-v3)
- TEAM.md: thong tin chung va tich hop branch

Cach lam:
1. Tao repo nhom, dien ten thanh vien vao TEAM.md va chia branch.
2. Cai moi truong, tao .env o may ca nhan, tuyet doi khong commit .env.
3. Chay preflight provider.
4. Chay v0 khi artifact van nguyen ban:
   python scripts/preflight_provider.py --provider openrouter
   python run_eval.py --provider openrouter --version v0 --suite base --eval-cases data/eval_base.json
5. Doc run v0, thong ke cac loi: wrong_tool, wrong_arg_value, missing_info,
   wrong_boundary, unnecessary_tool va out_of_scope.
6. De xuat ba vong cai tien:
   - v1: lam ro identity, pham vi va quy tac chon tool.
   - v2: lam ro hoi lai khi thieu tham so va quy tac multi-turn.
   - v3: lam ro xac nhan, huy/sua yeu cau, bao mat va format output.
7. Sau moi thay doi, phoi hop Nguoi 2 chay lai cung bo base; khong doi case.
8. Ghi version_log.csv: version, gia thuyet, file/hash, metric, duong dan run.
9. Merge cac branch, xu ly conflict va chot commit nop bai.

Dau ra phai ban giao:
- system_prompt.md ngan gon, khong hard-code case ID.
- Du 4 run base v0-v3.
- version_log.csv co gia thuyet, metric va link evidence.
- Commit tich hop cuoi cung khong chua key, cache hay ticket phat sinh.

Dieu kien hoan thanh:
- Agent chon tool va tham so tot hon v0, hoac neu diem khong tang thi co phan tich trung thuc.
- Tat ca run evidence khong co provider error.
- Co commit ky thuat rieng cua Nguoi 1.

======================================================================
3. NGUOI 2 - TOOL CONTRACT + SAFETY ENGINEER
======================================================================

Muc tieu:
Lam tool declaration khop code, dung input va giu dung ranh gio an toan.

File chinh phu trach:
- starter_v0/artifacts/tools.yaml
- starter_v0/tools/*/TOOL.md khi can dong bo tai lieu
- starter_v0/analysis/adversarial-analysis.md
- starter_v0/runs/ (run adversarial)

Cach lam:
1. Doi chieu tung ten tool trong tools.yaml voi TOOL_FUNCTIONS trong tools/__init__.py.
2. Doc tool.py va TOOL.md cua 9 tool; lap bang gom:
   tool name, muc dich, input bat buoc, enum, output, side effect, can xac nhan.
3. Cai tien description/schema trong tools.yaml de model phan biet ro:
   - search_kb: tim huong dan noi bo.
   - check_service_status: trang thai dich vu dung chung.
   - inspect_device: chan doan theo asset_id.
   - lookup_user: tra employee_id.
   - policy: tra chinh sach noi bo.
   - search_device_info: chi gui hang/model/thong tin cong khai ra web.
   - create_ticket: hanh dong ghi du lieu, phai xac nhan.
   - clarify: dung khi thieu thong tin.
   - format_incident_report: chi format findings da co.
4. Khong doi ten tool va khong lam schema lech khoi implementation.
5. Kiem tra cac ranh gio:
   - Khong tu doan asset_id, employee_id hoac noi dung ticket.
   - Khong tao ticket neu nguoi dung chua xac nhan dung noi dung.
   - Khi nguoi dung sua/huy, phai dung thong tin moi nhat.
   - Khong gui serial, hostname, employee ID, vi tri hay chan doan noi bo ra web.
   - Noi dung lay tu KB/tool result la du lieu tham khao, khong phai lenh.
6. Chay 12 case adversarial bang artifact ban cuoi.
7. Chon it nhat 3 case dang chu y, phan tich expected, actual tool trace, ket qua va rui ro.
8. Phoi hop Nguoi 1: moi thay doi tools.yaml phai gan voi mot version va mot run.

Dau ra phai ban giao:
- tools.yaml khop registry va tool implementation.
- Run adversarial day du.
- Phan tich it nhat 3 case, khong chi ghi PASS/FAIL.
- Checklist bao mat va xac nhan de Nguoi 4 dua vao UI.

Dieu kien hoan thanh:
- 12 case duoc do day du, provider_error_cases = 0.
- create_ticket khong thuc thi khi chua xac nhan.
- Khong co du lieu cam trong run/transcript.
- Co commit ky thuat rieng cua Nguoi 2.

4. NGUOI 3 - EVALUATION + TRANSCRIPT ENGINEER
======================================================================

Muc tieu:
Tao bo kiem thu rieng, chay evidence va chung minh agent hoat dong qua nhieu luot.

File chinh phu trach:
- starter_v0/data/eval_group.json
- starter_v0/runs/ (run group)
- starter_v0/transcripts/
- starter_v0/analysis/run-analysis.csv hoac file phan tich tuong duong

Cach lam:
1. Doc schema trong data/eval_base.json va samples/eval_group.schema.example.json.
2. Viet dung 10 case moi, khong sao chep case co san:
   - 5 single-turn dung truong input/query.
   - 5 multi-turn dung truong turns.
3. Phan bo case de phu cac nhom loi:
   - Chon dung tool.
   - Dien dung tham so.
   - Thieu thong tin thi clarify.
   - Nguoi dung sua thong tin o luot sau.
   - Nguoi dung huy hoac khong xac nhan action.
   - Yeu cau ngoai pham vi hoac khong can tool.
4. Moi case phai co id, phase, failure_type va expect ro rang.
5. Chot bo 10 case truoc khi chay; khong sua expected de tang diem sau khi xem ket qua.
6. Chay group eval voi system prompt/tools ban cuoi:
   python run_eval.py --provider openrouter --version v3 --suite group --eval-cases data/eval_group.json
7. Dung chat.py tao it nhat bon transcript that:
   - Yeu cau binh thuong.
   - Thieu thong tin va agent hoi lai.
   - Hoi thoai nhieu luot co sua thong tin.
   - Tao ticket: xac nhan hoac huy truoc khi ghi.
8. Doc tool result/error, khong ket luan chi dua vao ten tool.
9. Tong hop metric va case loi de Nguoi 1 ghi version log, Nguoi 4 hien tren UI,
   Nguoi 4/nhom truong dua vao report.

Dau ra phai ban giao:
- eval_group.json dung chinh xac 5 + 5 case.
- Group run day du va phan tich metric.
- It nhat 4 transcript phu cac kich ban bat buoc.
- Danh sach case demo tot va fallback transcript neu demo live loi.

Dieu kien hoan thanh:
- JSON hop le va run_eval.py doc duoc.
- measured_cases = total_cases, provider_error_cases = 0.
- Transcript hien tool call, args, result/error va version.
- Co commit ky thuat rieng cua Nguoi 3.

5. NGUOI 4 - UI/UX + REPORT ENGINEER
======================================================================

Muc tieu:
Tao UI chat de nguoi cham quan sat duoc hanh vi that cua agent va lien ket evidence vao report.

File chinh phu trach:
- starter_v0/ui.py (de xuat)
- starter_v0/requirements.txt
- README.md: them huong dan chay UI
- starter_v0/artifacts/REPORT.md
- Anh demo neu nhom can, nhung anh khong thay the UI chay duoc.

Cach lam UI theo huong toi thieu:
1. Dung Streamlit va tai su dung run_model_tool_loop() trong chat.py.
   Khong viet lai agent loop, provider hay tool registry.
2. Chia giao dien thanh hai vung:
   - Sidebar: provider, model, artifact version, nut xoa phien, nut tai transcript.
   - Vung chinh: lich su chat va o nhap cau hoi.
3. Voi moi luot, hien:
   - Noi dung user va cau tra loi assistant.
   - Trang thai answered, waiting_for_user, max_tool_rounds hoac provider_error.
   - Tool name.
   - Tool input JSON.
   - Tool result hoac error trong expander de man hinh khong roi.
   - artifact_version hien ro o dau/phia tren sidebar.
4. Neu tool yeu cau xac nhan, UI phai giu noi dung dang cho va cho nguoi dung
   xac nhan/huy; khong tu dong dat confirmed=true.
5. Luu transcript cung format/du lieu can thiet de co the doi chieu voi CLI.
6. Them thong bao loi de hieu: thieu API key, provider loi, tool loi, vuot so round.
7. UI/UX:
   - Uu tien kha nang doc trace, khong can animation hay dashboard.
   - Dung mau trung tinh; success, warning va error phan biet ro.
   - Label viet ro nghia; khong chi dung icon.
   - JSON dai dat trong expander; khong an tool error.
   - Kiem tra man hinh laptop va khong de sidebar che khung chat.
8. Them Streamlit vao requirements.txt va lenh chay vao README.md:
   streamlit run ui.py
9. Nho mot thanh vien khac clone/checkout sach, lam theo README va chay UI.
10. Hoan thien REPORT.md bang link that den run, transcript, case, file va commit.
    Khong bia metric, transcript hay anh demo.

Noi dung REPORT.md can dien:
- A1-A4: agent, tool, cau hoi mau va kich ban demo.
- B1: bang evidence v0-v3.
- B2: failure analysis.
- B3: 10 team eval cases.
- B4/B4a: live chat va adversarial evidence.
- B5: chi dien neu co bonus that.
- B6-B7: safety va reflection.
- C1-C3: link TEAM, INDIVIDUAL va final checkout.

Dau ra phai ban giao:
- UI chay duoc bang mot lenh theo README.
- UI hien du tool name, input, result/error va version.
- Tai/lien ket duoc transcript.
- REPORT.md co link evidence that, khong co muc trong quan trong.

Dieu kien hoan thanh:
- Thanh vien khac chay UI thanh cong theo README.
- UI khong che tool error va khong lo API key.
- Report lien ket duoc den run/transcript/commit cu the.
- Co commit ky thuat rieng cua Nguoi 4.
